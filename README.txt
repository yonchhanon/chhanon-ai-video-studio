CHHANON AI VIDEO STUDIO — PHASE 1 PROTOTYPE

What is included:
- Responsive Khmer/English interface
- Home dashboard and navigation
- Create and save project metadata in this browser
- Basic Story Maker text field saved in this browser
- Character Library saved in this browser
- Import and preview one local video file

Important limitations:
- This is a front-end prototype, not a production AI service.
- No AI video generation, user accounts, cloud sync, multi-clip timeline, or MP4 export yet.
- Browser-local data stays on this device/browser and is not automatically backed up.
- Imported video is previewed locally; it is not uploaded to a server.

To test:
1. Open index.html in a modern browser.
2. Choose Khmer or English.
3. Create a project, write a story, add a character, or preview a video.

To publish:
Upload the contents of this folder to a static hosting provider such as Netlify.
